#### Main description

On-device models are fast, private and free to run, but they aren't on every device. #BuildHybridAI challenges you to build apps that use both. Using the Firebase AI Logic Hybrid Inference SDK, your app runs prompts on-device when a local model is available and falls back to the cloud when it isn't.

Build for at least one platform: Web (Chrome) or Android with Gemini Nano 4, or iOS with Apple Foundation Models, all through Firebase AI Logic. Want to go further? Apps that run across multiple platforms will be given strong consideration for the Grand Prize, since that's where a single hybrid SDK really shines. An outstanding single-platform app can still win. For example: a notes app that summarizes on-device offline and hands long documents to the cloud. New projects and significantly updated existing apps are both eligible, and the competition is open to individuals, teams and organizations in most countries (see the [Official Rules](https://firebasehybridaihackathon.devpost.com/rules)).

###  Requirements

#### Requirements

##### What to Build

Build a Gen AI application using Firebase AI Logic along with supported firebase products such as: AppCheck, RemoteConfig, Firestore and Authentication.

_Build for one of these platforms:_

  * Web (Chrome): Gemini Nano 4 via Firebase AI Logic. Build a web app or a Chrome extension.
  * Android: Gemini Nano 4 via Firebase AI Logic.
  * iOS: the [Apple Foundation Models](https://firebase.google.com/docs/ai-logic/apple-foundation-models-framework/get-started?api=dev) API for local execution via Firebase AI Logic.

Firebase AI Logic requires App Check; debug tokens are accepted in submissions. You're encouraged to use other Firebase products, such as Remote Config, Firestore and Authentication.

##### How to Build

Build with any AI coding tool or IDE you like, such as Antigravity, Android Studio, Claude Code, Codex or Cursor, as long as your app's AI runs on Firebase AI Logic. Google tools like Antigravity are recommended. Coding agents work best with [Firebase Agent Skills](https://firebase.google.com/docs/ai-assistance/agent-skills), which come built into Antigravity and Android Studio.

##### What to Submit

  * Include a Project built with the required developer tools and meets the above Submission Requirements.
  * Select at least one platform which represents your project. Please note that Submissions will be associated with the platform selected. The Sponsor and Administrator reserve the right to reassign a Submission from one category to another if applicable.
  * For existing apps
    * If Entrant uses an app that existed before the submission period:
      * Must provide a summary of what you built during the submission period.
    * If Entrant uses an app that existed before the submission period and already has public usage:
  * Include a text description that details the core value the existing app provides to the new project
  * Optional: Include how widely it has been used
  * Include a text description that should include how you used Firebase AI Logic, a summary of the Project’s features and functionality, and a value proposition.
  * Provide a URL to your code repository for judging and testing on either GitHub or GitLab. The repository must contain all necessary source code, assets, and instructions required for the project to be functional, detail the value proposition, and must demonstrate the use of Firebase AI Logic at runtime in your code — imported and actually called (a library import, an app/backend entry point, or a loaded agent/flow/MCP config), not just named in the README.
    * Must have an open source license.
    * The repository must be public and open source by including an open source license file. This license should be detectable and visible at the top of the repository page (in the About section). Although Apache is preferred, any open source license can be used.
  * Include a demonstration video of your Project. The video portion of the submission must meet the following criteria:
    * Should include footage that shows the Project functioning on the platform(s) for which it was built.
    * It should not be longer than 3 minutes. If it is longer than 3 minutes, only the first 3 minutes may be evaluated.
    * It must conform to the technical requirements set forth on the Contest site, including that the Submission must be uploaded to and made publicly visible on YouTube and a link to the video must be provided on the Submission form on the Contest Site.
    * It must be in English or include English subtitles.
  * Entrants are strongly encouraged to
    * Include a URL to the Project for judging and testing, such as web UI, Chrome Extension, mobile app, etc. A hosted project is highly encouraged.
    * Use Google IDEs (Antigravity, Android Studio, etc), however they can use any tool they want, provided the implementation is Firebase AI Logic
    * Use Coding agents with Firebase agent skills (compatible with Antigravity, Claude, etc).

You may submit more than one project if each is substantially different. All submission materials must be in English, and your project must be available free of charge.
